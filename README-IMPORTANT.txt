سنتر سعيد التعليمي — Saeed Center Pro 4.0
==========================================

هذه النسخة Full-Stack بخادم Node.js وقاعدة SQLite مشتركة، ومبنية فوق النسخة السابقة مع ترحيل تلقائي يحافظ على السجلات القديمة.

تشغيل ويندوز
------------
1) تحتاج Node.js 22 أو أحدث.
2) افتح START-SITE.bat فقط.
3) افتح العنوان الذي يظهر في نافذة CMD.
4) لوحة الإدارة: /admin.html
5) أول تشغيل فقط: أنشئ حساب المدير العام.
6) لا تستخدم Live Server ولا تفتح index.html مباشرة.
7) لا تحتاج npm install؛ لا توجد Runtime dependencies خارجية.

نظام الطالب وولي الأمر الجديد
-----------------------------
- رقم الطالب ممنوع يتكرر في تسجيل جديد.
- رقم ولي الأمر يجب أن يكون مختلفًا عن رقم الطالب.
- نفس رقم ولي الأمر مسموح أن يرتبط بأكثر من ابن/ابنة.
- عند اعتماد التسجيل (Confirmed) يصدر رقم متابعة فريد مثل SC-2026-00001.
- بوابة ولي الأمر تعمل بـ: رقم المتابعة + رقم ولي الأمر المسجل.
- رقم المتابعة منفصل عن رقم طلب التسجيل.
- يمكن للطالب أن يضم أكثر من مادة/مجموعة داخل نفس الملف دون تكرار رقم الهاتف.
- لكل مادة: المدرس، المجموعة، الموعد، القاعة، والحالة.
- نقل الطالب إلى مجموعة/مدرس آخر لا يمسح السجل السابق؛ الاشتراك القديم يغلق بتاريخ وسبب ويظل محفوظًا.
- كل الامتحانات والدرجات محفوظة تاريخيًا.
- يمكن رفع صورة ورقة الامتحان وربطها بالدرجة والمادة والمدرس والمجموعة.
- الحضور يعرض كل الحصص: حاضر / غائب / اعتذار، مع عدد مرات الغياب وتواريخه ومادته.
- المالية تعرض إجمالي المطلوب، المدفوع، المتبقي، الاشتراكات، وسجل كل دفعة وإيصال.
- رسائل خاصة لولي أمر طالب ورسائل جماعية لأولياء أمور مجموعة.
- كل رسالة تظل محفوظة بالتاريخ، وتظهر كـ "جديدة" ثم "تمت القراءة".
- الرسالة الجماعية تحفظ قائمة المستلمين وقت الإرسال؛ إذا انتقل الطالب لاحقًا لا تضيع الرسائل القديمة ولا تصله رسائل المجموعة القديمة المستقبلية.
- ملف الطالب في الإدارة يجمع: البيانات، ولي الأمر، المواد، المجموعات الحالية والقديمة، الحضور، الامتحانات وصورها، الدرجات، المالية، الرسائل، وسجل إرسال رقم المتابعة.

إرسال رقم المتابعة لولي الأمر
-----------------------------
عند تحويل حالة الطلب إلى "مؤكد":
1) يصدر رقم المتابعة تلقائيًا.
2) يتم تجهيز رسالة باسم الطالب + رقم المتابعة + رابط بوابة ولي الأمر.
3) إذا كان PARENT_NOTIFY_WEBHOOK_URL مضبوطًا في .env، يرسل الخادم الرسالة تلقائيًا إلى مزود الرسائل.
4) إذا لم يوجد مزود خارجي، تحتفظ الإدارة بالرقم وتستطيع فتح رسالة WhatsApp جاهزة بزر واحد وإرسالها يدويًا.

مهم: لا يمكن لخادم ويب إرسال WhatsApp/SMS حقيقي من رقم هاتف بدون مزود/حساب API خارجي. المشروع لا يزوّر حالة "تم الإرسال"؛ يسجل Sent فقط إذا رجع مزود الرسائل بنجاح.

الحفاظ على البيانات القديمة
----------------------------
- عند تشغيل هذه النسخة على قاعدة بيانات النسخة السابقة، يتم إضافة الجداول والأعمدة الجديدة تلقائيًا بدون حذف registrations أو attendance أو payments أو subscriptions أو grades أو messages القديمة.
- كل تسجيل قديم يُرحّل تلقائيًا إلى سجل المواد/المجموعات الجديد.
- التسجيلات القديمة المؤكدة تحصل على رقم متابعة تلقائيًا.
- لا تحذف مجلد data عند تحديث نسخة مستخدمة فعليًا.
- قبل أي تحديث إنتاجي خذ نسخة احتياطية من data/saeed-center.db ومجلد uploads.

وظائف الإدارة الأساسية
----------------------
- مستخدمون وصلاحيات: مدير عام، مشرف، استقبال، مدرس.
- مراحل، صفوف، مواد، مدرسون، مجموعات.
- سعة المجموعة، المتبقي، Waiting List والترقية التلقائية.
- إضافة أكثر من مادة لنفس الطالب.
- نقل مادة/مجموعة مع حفظ التاريخ القديم.
- حضور بالحصة وقائمة الطلاب الفعلية من الاشتراكات الحالية.
- درجات واختبارات وصورة ورقة الامتحان.
- اشتراكات ومدفوعات ومتأخرات وإيصالات وكشف حساب PDF.
- رسائل خاصة وجماعية مع حالة القراءة.
- ملفات وملازم حسب المجموعة.
- استيراد XLSX/CSV وتصدير XLSX حقيقي.
- Audit Log.
- تقارير الإيرادات والمجموعات والمدرسين.

الدفع الإلكتروني
----------------
البنية موجودة ويمكن ضبط PAYMENT_CHECKOUT_URL أو رابط الدفع من لوحة الإدارة.
التأكيد الآلي للدفع يحتاج مفاتيح مزود الدفع الحقيقي وWebhook/Callback من حساب Merchant.

النشر
-----
- الاستضافة يجب أن تشغل Node.js 22+ وتوفر Persistent Storage.
- GitHub Pages وحده لا يصلح للنسخة Full-Stack.
- اضبط HOST=0.0.0.0 وNODE_ENV=production على السيرفر.
- استخدم HTTPS.
- ضع الدومين الحقيقي في config.js > siteUrl وحدّث sitemap.xml وrobots.txt.
- لا ترفع .env إلى GitHub.

الفحص
-----
شغّل:
  npm run check
أو:
  node scripts/self-check.js

اختبارات النسخة 4.0 شملت:
- رفض تكرار رقم الطالب.
- رفض تساوي رقم الطالب وولي الأمر.
- السماح بنفس رقم ولي الأمر لإخوة مختلفين.
- إصدار رقم متابعة عند الاعتماد.
- إضافة مادتين لنفس ملف الطالب.
- ظهور الطالب في كشف حضور المادة الثانية.
- تسجيل غياب وحسابه في بوابة ولي الأمر.
- رفع رابط صورة امتحان وظهورها مع الدرجة.
- حساب المدفوع والمتبقي.
- رسائل خاصة وجماعية وحالة القراءة.
- نقل مجموعة مع بقاء السجل والرسائل القديمة.
- ترحيل قاعدة بيانات قديمة دون حذف بياناتها.

لو عندك بيانات فعلية في نسخة قديمة على جهازك
-------------------------------------------
1) أغلق النسخة القديمة تمامًا.
2) افتح UPGRADE-KEEP-OLD-DATA.bat داخل النسخة الجديدة.
3) الصق مسار مجلد النسخة القديمة.
4) الأداة تنسخ قاعدة البيانات وuploads مع الاحتفاظ بنسخة احتياطية من قاعدة النسخة الجديدة إن وجدت.
5) بعدها افتح START-SITE.bat؛ Migration 4.0 تعمل تلقائيًا.
